Progetto Paradigmi - Gestione Bacheca
===================================

Descrizione
-----------
Questo progetto Java realizza una semplice applicazione di "bacheca" per gestire annunci di vendita e acquisto. Contiene componenti per CLI, GUI, utilità di file e test unitari.

Struttura del progetto
----------------------
- src/upoBacheca/ : classi principali del dominio (Annuncio, Bacheca, Utente, ecc.)
- src/UpoCli/ : interfaccia a riga di comando (BachecaCli)
- src/UpoGui/ : interfaccia grafica (BachecaGui)
- src/upoMain/ : punto di ingresso (Main.java)
- src/UpoTest/ : test JUnit
- src/upoUtil/ : classi utilitarie (file, comparatori)

Esecuzione
---------
Dopo la build, avviare l'applicazione (se il packaging è configurato) o eseguire Main tramite l'IDE.
